# Bashar Abied · Portfolio

Portfolio, CV and intro video of **Bashar Abied (بشار عبيد)**, Consulting Director at PwC Middle East, former CTO and Solutions & Software Architect.

**Live:** https://oriebalzyuot96.github.io/bashar/ · العربية: https://oriebalzyuot96.github.io/bashar/ar/
**CV (PDF):** https://oriebalzyuot96.github.io/bashar/Bashar-Abied-CV.pdf
**Intro video:** https://oriebalzyuot96.github.io/bashar/assets/bashar-intro.mp4

Built with Astro (EN + Arabic RTL). All content lives in `src/data/profile.ts`.

- `npm run dev` / `npm run build`
- `tools/cv/cv.html` is the CV source (rendered to PDF with Playwright).
- `tools/reel/` holds the intro reel: `intro.html` (scenes), `music.mjs` (original synthesised soundtrack) and `render.mjs` (frame-exact render + ffmpeg mux to MP4/WebM).
